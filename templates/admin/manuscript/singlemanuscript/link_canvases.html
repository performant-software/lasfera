This page allows you to connect pages from a IIIF manifest to folios in the manuscript, such that the IIIF manifest will automatically change pages as users read the manuscript.

How it works:

  • Each row is one image (canvas) from this manuscript's IIIF manifest.
  • Look at the image, work out which folio of the manuscript it shows, and enter that folio's number (for example 12r) to link the image to the text.
  • You can click each image to see it larger.
  • For a quick start, use Fill in folio numbers from manifest labels: it copies an image's manifest label into its empty folio number box when the label appears only once in the manifest and matches a Folio record that isn't linked yet. Check the results before saving.
  • Clear a folio number to unlink it.
  • Use the Show menu to narrow the list, for example to images not linked yet, your unsaved changes, or rows with problems that need fixing before you can save.
  • Use the Save button at the bottom of the page to save your changes when finished.
  • A Folio record also needs a line range before the text can turn to its image. Add it on the Folio record's own page after saving.
Note that the IIIF institution's own label for each image is shown under "Manifest label" for reference only; it may be wrong or repeated.

Note also that this page only handles which Folio record is linked to which image. Folio records are never renamed or deleted here, so their toponyms stay attached; to correct a folio number itself, edit the Folio record. {% if can_create %}Entering a folio number that has no Folio record yet will create a new one on save.{% endif %}
